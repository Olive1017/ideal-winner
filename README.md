# Shell Convert Tool

一个用于将壳牌订单数据转换为 SDCC 系统导入格式的自动化工具。

## 功能特点

- 🔄 自动读取和转换壳牌订单 Excel 数据
- 📊 支持车型映射，自动匹配车型信息
- ⚡ 批量处理订单数据，提高工作效率
- 🖥️ 现代化图形界面，操作简便

## 安装依赖

```bash
pip install pandas openpyxl customtkinter
```

## 使用方法

1. 运行程序：
   ```bash
   python ui.py
   ```

2. 在界面中：
   - 上传壳牌订单 Excel 文件（必选）
   - 上传车型映射文件（可选）
   - 点击"开始转换"按钮
   - 转换完成后点击"导出"保存文件

## 数据转换规则

- **导单日期**：基于文件创建时间自动获取
- **时间计算**：
  - 客户订单时间 = 导单日期 + 1天
  - 计划发货/到达时间 = 导单日期 + 3天
- **订单号**：提取第一个订单号
- **物料编码**：提取数字部分
- **车型映射**：基于交货单号自动匹配
